# Prompts for any AI

Plain-text versions of every agent. They work in any AI chat (ChatGPT, Gemini, Claude.ai, local models) because they only need text.

- `00-orchestrator.md` - the main agent; paste it and it will run the stages in order and stop for your decisions.
- One file per specialist - paste one when you want just that job done.
- `../portable/all-in-one.md` - everything in a single file, for chats where you can paste only once.

Chat tools usually can't read your files, so paste `docs/brand-profile.md` and the memory registers into the chat, and save any register updates the agent gives you back into `memory/` yourself.

Nothing here can post to LinkedIn. You publish manually after you approve.
