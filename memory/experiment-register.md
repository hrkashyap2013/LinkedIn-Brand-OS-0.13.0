# Experiment Register

One primary variable per experiment. Results must come from actual LinkedIn evidence, never pre-filled. States: LOCKED, CORE, TEST, RETIRED. Decisions: ADOPT, MODIFY, CONTINUE TESTING, RETIRE, INSUFFICIENT EVIDENCE.

Who may write here: Experiment, Measurement, Learning. Rows are added only through the write guard (`scripts/memory_guard.py`).
